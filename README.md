# Ammar Mohammad — Personal Portfolio 🇸🇾

موقع شخصي احترافي وتفاعلي لعمار محمد، مبني بالكامل بـ HTML + CSS + JavaScript، ومجهز للنشر على GitHub Pages.

## التشغيل
لا يحتاج إلى Backend أو Node.js.

1. ارفع جميع الملفات إلى Repository على GitHub.
2. من Settings → Pages اختر Deploy from a branch.
3. اختر `main` و`/ (root)`.
4. احفظ، وسيظهر الموقع على رابط GitHub Pages.

## الصورة الشخصية
ضع صورتك باسم:
`assets/ammar.jpg`

ثم استبدل عنصر `.portrait-placeholder` في `index.html` بعنصر صورة مثل:
`<img src="assets/ammar.jpg" alt="عمار محمد">`
